# 角色、UI、游戏与摄影案例

本册覆盖 16 个案例。UI 图片是视觉设计稿，不是可交互代码；真实产品界面仍需后续
实现。摄影与人物案例要明确是否使用用户提供的身份参考。

## D01 专业头像（Image Factory 后续）

- **用户输入**：“根据我的照片做一张自然的职业头像，不要过度磨皮。”
- **批次条件**：头像；主体参考；自然摄影；中性背景；身份一致。
- **自动处理**：提取脸型、发型和肤色锚点，使用自然侧光和可信皮肤纹理。
- **交付**：头像原图和社交平台派生尺寸。
- **验收**：身份可识别；没有塑料皮肤；背景不抢主体。
- **参考能力**：Profile/Avatar、Realistic Photography。

## D02 街头潮流头像（Image Factory 后续）

- **用户输入**：“做一个红色背景的街头风头像，服装由我提供参考。”
- **批次条件**：头像；主体 + 服装参考；高对比；方形。
- **自动处理**：锁定人物与服装，把姿态、红色背景和轮廓光组合为一个方向。
- **交付**：方形头像。
- **验收**：服装图案不乱变；人物轮廓清楚；没有假 Logo。
- **参考能力**：YouMind 案例 34457。

## D03 水彩人物插画（Image Factory 后续）

- **用户输入**：“把这张人物照片转成松散但五官准确的水彩插画。”
- **批次条件**：编辑；主体参考；水彩；保留姿势和身份。
- **自动处理**：提取姿势、面部比例、衣服和背景层次，改变媒介与笔触。
- **交付**：水彩人物图和参考分析记录。
- **验收**：人物身份和姿势保留；水彩边缘自然；不混入油画或 3D。
- **参考能力**：YouMind 案例 33664、Watercolor。

## D04 3D 潮玩角色（Image Factory 后续）

- **用户输入**：“把原创角色做成高级盲盒公仔展示图。”
- **批次条件**：角色/IP；3D；主体参考；包装、底座、材质。
- **自动处理**：保留脸和服装锚点，定义公仔比例、搪胶材质、包装和棚拍光线。
- **交付**：公仔主视觉和包装展示图。
- **验收**：角色身份保留；包装文字少且准确；不是通用玩具脸。
- **参考能力**：`3d-collectible-toy`。

## D05 武侠角色主视觉（Image Factory 后续）

- **用户输入**：“设计一个原创少女武术角色，水墨飞溅但不要现成 IP。”
- **批次条件**：角色；原创；动漫插画；武术；水墨效果。
- **自动处理**：定义服装轮廓、武器、姿态、线条、墨迹和强调色。
- **交付**：角色主视觉和设定摘要。
- **验收**：动作结构合理；人物原创；水墨效果不遮挡主体。
- **参考能力**：Game Asset 案例 33776、Ink/Chinese。

## D06 Q 版 RPG 活动图（Image Factory 后续）

- **用户输入**：“给原创手游做一个 Q 版寻宝活动 KV。”
- **批次条件**：游戏素材；Q 版；活动主视觉；角色与宝箱；无真实商标。
- **自动处理**：定义角色数量、动作、奖励焦点、魔法效果和标题留白。
- **交付**：活动 KV 和无字版本。
- **验收**：角色数量正确；焦点集中；画面不拥挤。
- **参考能力**：Game Asset 案例 34306、Gaming。

## D07 金融 App 仪表盘（Image Factory 后续）

- **用户输入**：“为虚构理财 App 做一张深色仪表盘视觉稿。”
- **批次条件**：UI/网页；桌面；仪表盘；深色；虚构数据。
- **自动处理**：组织顶部栏、资产卡、趋势图、交易列表和导航，填入明确的虚构文案。
- **交付**：桌面 UI 视觉稿。
- **验收**：信息架构合理；数字和标签可读；不冒充真实金融数据。
- **参考能力**：`ui-screenshot-system`、UI/UX Mockups。

## D08 小红书风内容 App 页面（Image Factory 后续）

- **用户输入**：“做一个虚构生活方式社区的手机首页视觉稿。”
- **批次条件**：UI/网页；手机；内容流；卡片；底部导航。
- **自动处理**：定义状态栏、搜索、双列内容卡、互动信息和导航项。
- **交付**：手机界面视觉稿。
- **验收**：使用虚构品牌；组件对齐；文案无乱码；页面不是实现代码。
- **参考能力**：UI Screenshot、App/Web Design。

## D09 SaaS 落地页概念（Image Factory 后续）

- **用户输入**：“为 AI 会议总结工具做一张桌面落地页概念图。”
- **批次条件**：UI/网页；桌面；Hero + 功能模块；品牌色；精确标题。
- **自动处理**：组织导航、主标题、产品界面预览、三项能力和 CTA。
- **交付**：落地页视觉稿和文案清单。
- **验收**：层级符合网页逻辑；CTA 可读；不伪造真实客户 Logo。
- **参考能力**：UI Screenshot、Brand Systems。

## D10 像素游戏场景（Image Factory 后续）

- **用户输入**：“做一个雨夜港口的 16 位像素游戏背景。”
- **批次条件**：游戏素材；像素艺术；横版；雨夜；无角色或用户指定角色。
- **自动处理**：定义像素密度意图、前中后景、可行走区域、灯光和雨水反射。
- **交付**：游戏背景图。
- **验收**：像素风统一；路径可辨；没有混入写实纹理。
- **参考能力**：Pixel Art、Gaming。

## D11 等距城市模块（Image Factory 后续）

- **用户输入**：“做一套等距城市街区，用于经营游戏概念展示。”
- **批次条件**：游戏素材；等距；系列视觉；建筑与道路一致。
- **自动处理**：定义等距角度、网格、建筑模块、道路接口和统一材质。
- **交付**：多个街区模块和汇总预览。
- **验收**：角度和尺度一致；接口可以拼接；没有透视漂移。
- **参考能力**：Isometric、Architecture/Space。

## D12 建筑室内概念图（Image Factory 后续）

- **用户输入**：“设计一个木石材料的小型山间阅读室。”
- **批次条件**：建筑/空间；室内；自然材料；广角空间感；暖光。
- **自动处理**：定义视点、尺度、动线、木材、石材、窗景和光线方向。
- **交付**：室内概念图。
- **验收**：透视合理；材料关系可信；空间功能清楚。
- **参考能力**：`architecture-space`、Architecture/Interior。

## D13 纪实街头瞬间（Image Factory 后续）

- **用户输入**：“做一张雨天外卖员避雨的纪实街拍感图片。”
- **批次条件**：摄影；街头；抓拍；雨天；普通环境细节。
- **自动处理**：描述相机高度、动作瞬间、轻微运动模糊、湿路面和环境物件。
- **交付**：纪实风图片。
- **验收**：画面不像棚拍广告；动作可信；不添加可识别真实品牌。
- **参考能力**：`street-accident-moment`、Photography。

## D14 建筑微缩收藏品（Image Factory 后续）

- **用户输入**：“做一个白色石材微缩城市收藏品，像博物馆展品。”
- **批次条件**：概念产品；建筑；微缩模型；棚拍；无人物。
- **自动处理**：定义连续石材结构、地标数量、金属装饰、水景和展陈光线。
- **交付**：收藏品主视觉。
- **验收**：地标数量受控；材料连续；没有随机文字或人物。
- **参考能力**：Architecture/Space、Product/Food、micro-scale material control。

## D15 原创纹身图稿（Image Factory 后续）

- **用户输入**：“设计一张适合前臂的黑灰松鹤纹身稿，只要图稿，不要真人皮肤。”
- **批次条件**：角色/图形；纹身；黑灰；前臂纵向；负空间；原创。
- **自动处理**：定义松枝、鹤、云气、线条粗细、阴影和皮肤适配留白。
- **交付**：白底纹身设计稿和构图说明。
- **验收**：没有真实皮肤照片；线条可执行；主体不依赖现成 IP；负空间充分。
- **参考能力**：Tattoo Design、category mini-schema。

## D16 真实设备屏摄效果（Image Factory 后续）

- **用户输入**：“把我的网页截图放到真实笔记本屏幕里，做一张桌面工作场景照片。”
- **批次条件**：屏摄；UI 截图参考；写实摄影；桌面环境；屏幕内容保持。
- **自动处理**：锁定屏幕 UI，定义设备透视、环境反光、相机位置、桌面物件和自然光。
- **交付**：屏摄场景图和原始 UI 对照。
- **验收**：屏幕内容没有重排；透视和反光可信；设备上没有假品牌标识。
- **参考能力**：Screen Photography、UI Screenshot、capture context。
